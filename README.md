# Household Budget

A simple household budgeting app for tracking income and expenses, viewing budget history, and estimating household costs.

It starts with sample data for a fictional family in Indianapolis. Changes aren’t saved in the browser, so export your budget to Excel before leaving.

## Features

- Add and review monthly transactions
- Compare budgets with past spending
- Estimate heating-oil and water costs
- View a 7-day weather forecast
- Edit household details and budget benchmarks
- Export, import, or download an Excel template

Open index.html in a browser. Excel tools use SheetJS from a CDN, and the weather forecast needs an internet connection.

Website can be accessed at: https://dani-eng.github.io/household_budgeting_site/
